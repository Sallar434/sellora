# Project agents

These agent definitions come from [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) (MIT, see `LICENSE-agency-agents`).
Claude Code loads them from this folder automatically. Ask for one by name, for example "use the Reality Checker agent to review the checkout".

| Agent | Use it for |
|---|---|
| Reality Checker | Go/no-go review before a release; defaults to "needs work" |
| Evidence Collector | Screenshot-based QA of a feature |
| API Tester | Backend endpoint tests |
| Test Automation Engineer | Writing and fixing Playwright/vitest suites |
| Accessibility Auditor | Keyboard, contrast and screen-reader checks |
| Frontend Developer, UI Designer, UX Architect | Admin and storefront UI work |
| Backend Architect, Payments & Billing Engineer | API, VendOm Pay escrow and plans |
| Code Reviewer | Reviewing a change |
